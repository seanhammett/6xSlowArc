Installing the 27 October 2026 update (b)

This puts new software on the control box using a web page and a USB cable. The box keeps everything it remembers: every arc’s brightness and speed, the sequences and the WiFi login.

What’s new:

  • When the box is put into Performance, all six arcs go dark and stop, and stay that way until the sequence is started. The performance therefore begins from darkness.
  • Sequences can be deleted on the Sequences tab, and the box now holds 32 of them instead of 8.

This replaces any earlier update file you were sent. Use only the files in this folder.

About 10 minutes Google Chrome or Microsoft Edge The arcs pause for a minute or two

Before you start

  • A laptop with Google Chrome or Microsoft Edge. Safari and Firefox can’t do this.
  • A USB cable that carries data, to connect the laptop to the circuit board inside the control box. Many phone-charging cables only carry power and won’t work.
  • The file slowarc-2026-10-27b.bin saved on the laptop, for example in Downloads. Keep slowarc-2026-09-22-rollback.bin next to it, just in case.
  • A time when the arcs aren’t needed. They go dark and stop briefly, then come back by themselves.

The one rule: never press Erase Flash

Erase Flash

It wipes everything the box remembers, and the box would have to be set up again from scratch. Nothing in these instructions needs it. The only address you ever type is 0xE000.

Steps

  1. Plug in the cable

    Connect the USB cable to the socket marked UART on the small circuit board inside the control box, and to your laptop. Leave the box switched on.

    If the board has two sockets, UART is the one to use. There’s a fix in “If something goes wrong” if it doesn’t connect.

  2. Open the update page

    In Chrome or Edge, go to espressif.github.io/esptool-js. It’s the official tool from Espressif, the company that makes the chip in the box. Nothing gets installed on the laptop.

  3. Connect to the box

    Under Program, leave Baudrate as it is and click Connect. A small window lists devices: pick the one with CP210x or USB to UART in its name, then click Connect in that window.

    On the update page Connect
    espressif.github.io wants to connect to a serial port
    CP2102N USB to UART Bridge Controller

    When it has worked, the page says Connected to device: ESP32-S3 followed by some details.

  4. Type the address

    There’s a table with Flash Address and File, with one row already in it. Click into the Flash Address box, delete 0x1000, and type 0xE000: zero, the letter x, the letter E, then three zeros.

    The first row of the table
    Flash AddressFile
    0x10000xE000 Choose File No file chosen

    This address is what keeps the box’s settings safe, so check it twice.

  5. Choose the file

    In the same row, click Choose File (on some laptops it says Browse…) and pick slowarc-2026-10-27b.bin.

    Don’t click Add File. Leave Flash Mode, Flash Frequency and Flash Size as they are.

  6. Click Program and wait

    Click Program. A progress bar fills, which takes about a minute. Don’t unplug the cable or close the page while it’s moving.

    It’s finished when the text on the page ends like this
    Wrote 1213600 bytes (… compressed) at 0xe000 in … seconds. Hash of data verified. Leaving...

    The control box then restarts by itself.

  7. Disconnect

    Click Disconnect, unplug the USB cable, and close the box as you found it.

Check it worked

The status light is solid amber for a few seconds, then settles into a slow green pulse (Gallery) or blue blinking (Performance), the same as after switching the box on.

The arcs: in Gallery (green light), the bulbs fade back up one after another and the motors start turning, at their usual settings. In Performance (blue blinking), the arcs stay dark and still. That’s the new behaviour, not a fault: they start when the sequence button or ▶ Play is pressed.

▶

The web page: open the control page as usual and refresh it. If the box is in Gallery, click Performance at the top of the Control tab. The arcs fade to dark and stop, and the status box reads Sequence: … staged (arcs dark). Click Gallery to bring them back. Don’t press ▶ Play unless the performance is meant to start.

The sequences: on the Sequences tab, the same sequence is still selected, and a new Stored sequences card lists the same sequences as before, with “… of 32 slots used”. Don’t delete anything as a test.

If something goes wrong

The device list is empty, or the box isn’t in it
Try a different USB cable; that’s the most common cause. On Windows, wait a minute after plugging in and try again. Still nothing? Plug into the socket marked USB instead. The device is then called USB JTAG/serial debug unit.
Stuck on “Connecting…” or it says “Failed to connect with the device”
Refresh the page. Hold down the button marked BOOT on the circuit board, click Connect, and let go once it says Connected.
“Offset field in row 1 is not a valid address!”
The address was mistyped. It must be exactly 0xE000.
It stopped partway with an error, or the cable came out
Nothing is lost, but the box won’t run until an update completes. Click Disconnect, refresh the page, choose 115200 as the Baudrate (slower, more reliable), and start again from step 3.
The box is back, but something looks wrong
For example, red flashes that don’t stop, or arcs that don’t move. Put the previous version back (below), then call Sean. If the light flashes red, count the flashes.

Going back to the previous version

Follow the same seven steps, but in step 5 choose slowarc-2026-09-22-rollback.bin. The address is the same, 0xE000, and the box keeps its settings this way too.

The previous version is the 22 September 2026 one. It has no Delete buttons and holds only 8 sequences, and in Performance the arcs stay at their usual settings until the sequence starts instead of going dark. Settings and the WiFi login are shared by both versions. If more than 8 sequences were saved, the previous version shows only some of them, but none are erased: installing this update again brings them all back. A sequence that was deleted stays deleted.
